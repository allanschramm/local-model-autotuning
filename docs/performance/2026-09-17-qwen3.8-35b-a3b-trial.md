Acquire, validate, and run a full Objective Vector Trial (`agentic-full` Claw-15 + coding-10) for `empero-ai/Qwen3.8-35B-A3B-Distill-GGUF` (`Qwen3.8-35B-A3B-Q4_K_M.gguf`) at configured context 65,536 (`q4_0`), diagnosing and resolving RAM Circuit Breaker trips without reducing context size.

- **GPU:** Discrete NVIDIA GPU, 8 GB VRAM class (keepout clamp 7,932 MB).
- **System Memory:** 32 GB RAM class (31.9 GB total).
- **OS:** Windows (WDDM driver model).
- **Runtime:** `llama.cpp-releases/upstream/b10867` (nightly CUDA 13.3).

Metadata query (`scripts/model_info.py`):
- Architecture: `qwen35moe`, 41 blocks, 256 routed experts (8 active per token, 3.125% sparsity).
- KV cache size: `q4_0` @ 65536 consumes only ~734.7 MiB (GQA with `head_count_kv=2`).
- 4 embedded MTP nextn tensors detected: `blk.40.nextn.*`.

- **Model:** `Qwen3.8-35B-A3B-Q4_K_M.gguf`
- **Context:** `65536` (`q4_0` KV cache)
- **Status:** **`on_front`**
- **Throughput (`bench_tg`):** **33.5 t/s** (33.0, 33.5, 34.0)
- **Combined Generation TPS:** **42.8 t/s**
- **Peak VRAM:** **7.7 GB** (under 7.93 GB clamp, zero WDDM shared spill)
  - BigCode Hard: 0.1000 (1/10)

1. **Context is Inviolable:** Context size was never reduced. The KV cache was negligible (~735 MB); the memory pressure was 100% due to expert offload imbalance.
2. **MoE Expert Shifting:** Each expert layer in `Qwen3.8-35B-A3B-Q4_K_M` accounts for ~465.8 MiB. Placing 10 layers on GPU offloaded ~4.65 GB from CPU RAM to VRAM, eliminating the memory bottleneck and boosting throughput by +20%.

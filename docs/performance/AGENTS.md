# Historical runtime evidence extracts

## Purpose
Performance-only excerpts from mixed records preserved in the benchmark history.

## Ownership
Repository developers; parent docs/AGENTS.md. Leaf files share this contract.

## Local Contracts
- Every extract links to its immutable full source. It is a derived view, not a replacement session log or a fresh validation.
- Preserve measured values, units, dates and conditions; retain the distinction between estimate, proposal and measurement.
- Keep TPS, context, memory, configuration and runtime failure evidence. Task quality scores/rankings remain in the source archive.
- Historical smoke TPS and configured context do not establish long-context throughput or capability. Current safety and tuning contracts govern new runs.
- Do not copy private paths, alias inventories or machine identifiers into extracts.

## Work Guidance
- Repair projections against the original; never fill missing numbers from memory.

## Verification
- Source links identify a fixed commit; retained runtime numbers match it; links resolve. No quality-score columns or current instructions for retired CLIs.

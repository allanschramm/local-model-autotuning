# Runtime discovery and technique guides

## Purpose
Provisioning, hardware fit, inference engines, quantization, KV/offload and runtime-performance methodology. Quality harnesses, quality rankings and teaching are archived.

## Ownership
Repository developers; parent docs/AGENTS.md.

## Local Contracts
- Active instructions use the bounded tuning entrypoint and compatible prebuilt runtimes. Engine-specific research may remain reference-only where the current tuning protocol does not support that backend.
- No private paths, aliases or machine inventory. Numeric claims distinguish measurements, estimates and proposals.
- Preserve configured context and current safeguards. Archived commands are historical references, not runnable instructions.

## Work Guidance
- Per-model runtime evidence belongs to docs/models; immutable session records to docs/sessions; derived extracts to docs/performance.

## Verification
- Current commands and relative links resolve; no retired quality CLI is an active instruction.

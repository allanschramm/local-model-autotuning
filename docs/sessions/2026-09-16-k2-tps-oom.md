# 2026-09-16 — K2 7B + MoVA-36B-A4B TPS / small-ctx OOM diagnosis

## Goal

Diagnose why `K2-Horizon-7B-Q4_K_M.gguf` and `K2-Horizon-MoVA-36B-A4B-Q4_K_M.gguf`
run slow (prefill + TPS) and OOM even at small configured ctx, compared to
same-size rivals on the same rig. Prefill/TPS only — no IQ axis in this pass.

Prior ctx-cap guidance (`32k safe baseline` for 7B) did not answer the
small-ctx complaint, so this file reframes around weights, vocab, kernels,
and the MoVA offload gap, with a falsifiable A/B matrix.

## Commands (reproducible probes, no Trials)

All paths repo-relative. Adjust `<fork>` / `<tag>` to the extracted release
under `llama.cpp-releases/`. One Neighbor at a time. No autoloop.

### A — 7B FA-fallback check (same prompt, `cache_prompt=false`)

```bash
# Baseline under test (fork, symmetric q4_0):
llama-cli -m models/<publisher>/K2-Horizon-7B-Q4_K_M.gguf \
  -c 8192 -ngl 99 -fa on -ctk q4_0 -ctv q4_0 \
  -b 512 -ub 128 -t 8 --no-warmup \
  -p "<fixed 2k-token prompt>" -n 64 --single-turn

# Counter-probe, symmetric q8_0 (fast-path reference on default builds):
llama-cli -m models/<publisher>/K2-Horizon-7B-Q4_K_M.gguf \
  -c 8192 -ngl 99 -fa on -ctk q8_0 -ctv q8_0 \
  -b 512 -ub 128 -t 8 --no-warmup \
  -p "<same fixed 2k-token prompt>" -n 64 --single-turn
```

Record per run: `pp t/s`, `tg t/s`, GPU busy during prefill
(`nvidia-smi dmon` pegged vs idle), server-log offload/fallback lines.
Prediction: if q8 jumps ~10-30x with GPU pegged, the q4 path fell back
to CPU attention on this fork. Fix = stay symmetric `q8_0/q8_0` here or
rebuild fork with the all-quants FA kernels. See
[advanced-inference-optimizations.md](../discovery/advanced-inference-optimizations.md)
§3 and [mtp-baseline-guide.md](../discovery/mtp-baseline-guide.md) §2.

### B — 7B prefill-spike ladder (same `-c`, vary `-ub`)

```bash
# ub in {128, 256, 512}, all else fixed from the A winner:
llama-cli -m models/<publisher>/K2-Horizon-7B-Q4_K_M.gguf \
  -c 8192 -ngl 99 -fa on -ctk <A-winner> -ctv <A-winner> \
  -b 512 -ub <128|256|512> --parallel 1 --no-warmup \
  -p "<same fixed prompt>" -n 64 --single-turn
```

Prediction: OOM disappearing at lower `ub` with identical `-c` proves
logits/scratch spike (250k vocab), not KV exhaustion. Climb back up only
while peak stays under keepout. Background:
[kv-cache-architecture-scaling.md](../discovery/kv-cache-architecture-scaling.md),
[local-models-low-vram-configs.md](../discovery/local-models-low-vram-configs.md) §3.

### C — 7B output-head offload probe

```bash
llama-cli -m models/<publisher>/K2-Horizon-7B-Q4_K_M.gguf \
  -c 8192 -ngl 99 -fa on -ctk <A-winner> -ctv <A-winner> \
  -b 512 -ub <B-winner> --parallel 1 --no-warmup \
  --override-tensor "output.weight=CPU" \
  -p "<same fixed prompt>" -n 64 --single-turn
```

Prediction: peak drops several hundred MB at a small per-token PCIe cost;
removes the WDDM pager that costs 100x+. If tg drops >15%, revert — head
stays on GPU and fit must come from quant/`ub` instead. Open question from
[k2-horizon-7b.md](../models/k2-horizon-7b.md).

### D — MoVA offload-gap probe (small ctx, load-first)

```bash
llama-server -m models/<publisher>/K2-Horizon-MoVA-36B-A4B-Q4_K_M.gguf \
  -c 8192 -ngl 99 --n-cpu-moe <block_count> \
  -fa on -ctk q4_0 -ctv q4_0 -b 512 -ub 128 \
  --override-tensor "self_attn.v_experts.*=CPU" \
  --spec-type none --no-warmup --host 127.0.0.1 --port <test-port>
```

Check startup log: `mlp.experts` offload lines vs any
`self_attn.v_experts` lines. Prediction: `--n-cpu-moe` alone leaves MoVA
value experts resident (wrong regex scope); the explicit override drops
peak by GBs. Tensor prefix must be verified via `gguf_dump` against the
fork's `k2-horizon.cpp` names before trusting the pattern. If no drop,
prefix is wrong — do not conclude the gap is closed. Background:
[low-vram-optimizations.md](../discovery/low-vram-optimizations.md) §4,
[speculative-decoding-formats.md](../discovery/speculative-decoding-formats.md) §4b.

Stop rule: MoVA is a load-first target here. If D still exceeds keepout at
8192 + Q4, step to the Q3_K_M basename before raising ctx. Do not run
coding/agentic Trials on MoVA until a serving probe holds keepout.

## Findings (repo knowledge, desk pass — no new measurements yet)

- 7B is 9.0B physical (6.95B core + 2.05B untied vocab). KV `q4_0`
  40.5 KiB/token, 2.59 GiB @65k vs 0.56 GiB hybrid rivals (4.5x).
  Detail: [k2-horizon-7b.md](../models/k2-horizon-7b.md),
  [kv-cache-architecture-scaling.md](../discovery/kv-cache-architecture-scaling.md).
- 7B GGUF carries no MTP head, so the +46-80% dense-MTP lever rivals use
  does not apply. Detail:
  [speculative-decoding-formats.md](../discovery/speculative-decoding-formats.md)
  §4a, [mtp-baseline-guide.md](../discovery/mtp-baseline-guide.md) §4.
- `k2_horizon` requires the IFM fork; upstream support is a pre-release
  discussion, not a merged arch. Fork predates upstream FA-quant,
  CUDA-graph, `kv-unified`, and `repack` tuning the pinned release has.
  Reference: [llamacpp-toolset.md](../llamacpp-toolset.md) flag inventory.
- MoVA attention adds routed value experts (`v_router`, `v_experts`,
  `gate_proj`, grouped RMSNorm, query_key_norm) inside attention. Stock
  `--n-cpu-moe` matches FFN experts only, so MoVA weights stay resident
  unless explicitly overridden. MoE spec loss on CPU offload is already
  durable on this rig — keep `--spec-type none` for MoVA probes.
- 250k vocab inflates logits/scratch per prefill step (~65% over 152k
  class) independent of ctx length. Small-ctx OOM on 7B is consistent
  with spike, not KV.

## Errors

- Earlier guidance stopped at "cap 7B at 32k". Correct for 65k paging,
  insufficient for the reported small-ctx OOM + slow TPS. This file
  corrects that scope.
- "K2 35B" basename used in operator notes. No such size exists; future
  rows must use `K2-Horizon-32B-*` or `K2-Horizon-MoVA-36B-A4B-*`
  basenames ([ADR 0012] basename rule).

## Decisions

- Probes run A → B → C for 7B, D standalone for MoVA. No combined
  changes, no autoloop, no Trial until a probe holds keepout with
  repeatable pp/tg.
- 7B daily fit stays Q4_K_M unless C fails; Q4_0 (smaller file) is the
  fallback, selective-Q6-attention build is quality-direction only.
- MoVA stays load-first / IQ-probe-only at 8k on this rig class. Speed
  comparisons against 35B MoE rivals (peak ~4 GB via `--n-cpu-moe`) are
  invalid until D closes the resident gap.
- Upstream-merge trigger: when `k2_horizon` lands in mainline, re-bench
  the A winner verbatim on the pinned release before changing anything.
